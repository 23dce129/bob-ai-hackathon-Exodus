# Project Documentation Context (Non-Obvious Only)

This file provides guidance to agents when working with code in this repository.

- `docs/template-guide.md` is the canonical reference for how all files should be structured and what evaluators look for. It is NOT a file to fill in — it's read-only guidance.
- `src/README.md` is a template placeholder, not documentation of actual code. Replace its content once source code is added.
- The evaluation rubric (in `docs/template-guide.md` §7) weights **Technical Implementation Quality** and **Innovation** at 25 pts each — judges read the actual source code, not just docs.
- `docs/architecture.md` is expected to contain a Mermaid diagram — the template guide shows an example using `graph TD` syntax.
- "IBM Bob integration" is a scored criterion (10 pts) — it must be load-bearing in the solution, not just mentioned.
